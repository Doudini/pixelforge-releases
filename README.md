# PixelForge releases

PixelForge is a node-graph texture and terrain generator for Windows, macOS and Linux.
This repository holds its release builds, and installed copies of PixelForge update themselves from here.

## Download

**[Latest release →](https://github.com/Doudini/pixelforge-releases/releases/latest)**

| Platform | File |
|---|---|
| Windows | `PixelForge-<version>-win-setup.exe` |
| macOS (Apple Silicon) | `PixelForge-<version>-mac-arm64.dmg` |
| Linux | `PixelForge-<version>.AppImage` or `pixelforge_<version>_amd64.deb` |

The `.zip`, `.yml` and `.blockmap` files are for the in-app updater; you don't need them.

More about PixelForge, including the changelog: [www.microbot.ch/pixelforge](https://www.microbot.ch/pixelforge/)
